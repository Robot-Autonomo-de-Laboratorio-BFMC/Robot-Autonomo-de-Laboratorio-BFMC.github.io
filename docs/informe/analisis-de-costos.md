# Análisis de costos

El desarrollo de un prototipo de robótica móvil implica una inversión significativa en hardware especializado. En este capítulo se detalla la estructura de costos directos asociados a la fabricación del vehículo y la implementación del entorno de validación.

El análisis se ha realizado bajo el enfoque de Costos Directos de Materiales. Es importante aclarar el alcance del presupuesto presentado. No se contabilizan costos de activos fijos preexistentes o de uso general, tales como computadoras portátiles para programación, monitores, herramientas de taller (destornilladores, soldadores, impresoras 3D) ni el costo de las licencias de software.
